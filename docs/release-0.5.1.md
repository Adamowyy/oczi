Oczi for Windows 0.5.1.

**Pin a piece of the screen.** A region you drag out stays where you put it — above everything, on any monitor, and over a game running in a window.

- **`Ctrl+Alt+Shift+P`** freezes the screen, you drag out a region, and it hangs there. Up to four at once, each dragged anywhere; the wheel resizes them and keeps their shape.
- **Draw on it or write on it** with the tools in its corner: a pen and a text tool, five colours, captions that take their size from the arrow keys and wrap inside the picture. The marks are part of the picture you copy, save or ask about.
- **Right-click a pin** to ask about it, copy the text inside it, copy the picture, save it as a file, fade it, or close them all. Asking leaves the pin exactly where it is.
- **The pin beside the ×** turns it into an ordinary window; **Shift with the wheel** fades it so what is underneath can be read through it.
- The shortcut is set in Settings → General, beside the other two.

**Oczi-Windows-0.5.1-setup.exe** is the ordinary Oczi, about 2 MB.
**Oczi-Windows-0.5.1-voice-setup.exe** is the same Oczi with dictation, a few hundred MB because the speech model is inside.

The installer is unsigned, so Windows shows its SmartScreen warning on the first run.
